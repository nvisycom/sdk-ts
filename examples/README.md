# Examples

Runnable examples for [`@nvisy/sdk`](../README.md). Each is self-contained:
`cd` into one, `npm install`, and follow its README.

- [`sdk-client`](./sdk-client/): using the SDK client (auth, listing,
  pagination, triggering a run, error handling).
- [`hono-webhook`](./hono-webhook/): a Hono server that verifies incoming
  webhooks with `@nvisy/sdk/webhooks`.

These are not part of the published package.
